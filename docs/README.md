## Overview

The **Co-living Community Platform** is a full-stack urban digital twin web application designed to visualize and analyze the proposed co-living development at Munich's Paketposthalle district. It integrates BIM models, geospatial information, and interactive 3D visualizations across multiple scales, providing comprehensive insights for urban planning, architectural design, and community engagement.

This platform combines cutting-edge web technologies with advanced architectural modeling to create an immersive experience that bridges the gap between digital design and real-world urban development.

## Core Features

### Three Interactive Visualization Modes

![three modes](https://raw.githubusercontent.com/blau1234/Co-living-Community/master/images/4.png)

#### 1. Project Mode
- **3D Building Visualization**: Explore detailed architectural models built with Three.js
- **Design Concept Exploration**: Interactive presentations of design principles and spatial organization
- **Functionality Analysis**: Examine different functional zones (residential, commercial, public spaces)
- **Virtual Tour**: 360-degree panoramic views rendered with D5render for immersive site exploration
- **Sustainability Metrics**: View environmental analysis results including solar potential, wind simulation, and energy efficiency
- **Public Space & Activities**: Visualize community amenities and social interaction spaces
- **Interactive Animations**: Hot air balloons, location pins, and dynamic visual elements

#### 2. IFC Mode
- **BIM Data Visualization**: Direct integration with Industry Foundation Classes (IFC) format
- **Component Highlighting**: Interactive selection and highlighting of building elements
- **Clipper Tool**: Cross-section views to explore internal building structure
- **Property Inspection**: Access detailed metadata for individual building components
- **Filter System**: Show/hide specific element types (walls, floors, roofs, etc.)
- **Real-time Model Manipulation**: Powered by @thatopen/components library

#### 3. City Mode
- **Urban Context**: 3D city-scale visualization using Cesium platform
- **3D Tiles Integration**: High-performance rendering of large-scale urban models
- **Geospatial Analysis**: View project within Munich's urban fabric
- **Multi-scale Navigation**: Seamless transition between city and project scales

### Additional Features
- **Message Board**: Community feedback and interaction system
- **Reservation System**: Space booking functionality
- **AI-Generated Ambience**: Background music generated by Stable Audio for enhanced user experience
- **Responsive UI**: Modern, intuitive interface built with Vue.js components
- **Loading Animations**: Smooth transitions and visual feedback

## System Architecture & Technology Stack

### Architecture Overview

![System Architecture](https://raw.githubusercontent.com/blau1234/Co-living-Community/master/images/1.png)

#### 1. Data Resource
- **BIM Data**: Revit models (LOD 300-400) converted to IFC, frag/json formats
- **City Data**: CityGML files processed into 3D Tiles and OBJ/glTF formats via FME
- **Point Cloud Data**: Raw 3D scan data processed with QGIS and CloudCompare

#### 2. Front-end
- **Project Mode**: `ProjectMode.js`, `DesignInfo.vue`, `FunctionalityViewer.js`, `SustainabilityViewer.js`, `PanoramaViewer.vue`, etc.
- **IFC Mode**: `IFCMode.js`, `ClipperManager.js`, `HighlightManager.js`, `HideManager.js`
- **City Mode**: `CityMode.js` with Cesium integration
- **Shared Components**: `Sidebar.vue`, `LoadingScreen.vue`, `MessageBoard.vue`, `Reservation.vue`, `MusicControl.vue`, etc.

#### 3. Cloud Server & Backend
- **Backend Services**: Node.js + Express (`server.js`, `message.js`)
- **Database**: MongoDB for user data and messages
- **Hosting**: Google Cloud Platform (App Engine)
- **Configuration**: `app.yaml` for deployment settings

### Core Dependencies

**Frontend:**
- Vue.js 3.3 - Progressive JavaScript framework
- Three.js 0.160 - 3D graphics library
- @thatopen/components 2.4.3 - BIM components library
- Cesium 1.125 - Geospatial 3D mapping platform
- GSAP 3.12 - Animation library
- Vite 5.0 - Build tool and dev server

**Backend:**
- Node.js 18+ - JavaScript runtime
- Express 4.18 - Web application framework
- Axios 1.7 - HTTP client

**Database:**
- MongoDB - NoSQL database for flexible data storage

## Quick Start

### Prerequisites
- Node.js >= 18.0.0
- npm package manager

### Run Locally

1. Install dependencies
```bash
npm install
```

2. Start the development server
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:8888`

> **Note**: This is an academic demonstration project developed at TUM. The application uses pre-configured API keys for Cesium Ion and cloud storage. For production deployment or custom configuration, please refer to `.env.development`, `.env.production`, and `app.yaml` files.
